# 아몰랑아일랜드 - 같이 낚시하고 힐링해요

링크만 누르면 로그인 없이 누구나 들어와서 같이 노는 3D 낚시 섬입니다.
Cloudflare 무료 플랜으로 운영할 수 있습니다.

- 섬 하나에 최대 40명이 들어갑니다. 꽉 차면 2번 섬, 3번 섬…으로 자동으로 넘어갑니다(최대 30개).
- 💬 채팅: 같은 섬 사람끼리 이야기해요. 섬마다 최근 50개만 서버에 남고, 오래된 것은 자동으로 지워집니다. 욕설·링크·전화번호는 서버에서 가려 줍니다(완벽하지는 않음).
- 🎣 낚싯대 ★1~★5 / 물고기 ★1~★5, 🐉 용왕님 상점(사기·팔기, 돈 단위 '몰랑'), 🎒 가방, 🍳 모닥불 요리(먹으면 ★+1), 🗺️ 지도, 다른 사람 수조 구경.
- 💾 아이디·비밀번호 계정: 옷·물고기·몰랑·장비·수조·도감이 서버(Durable Object SQLite)에 저장됩니다. 비밀번호는 PBKDF2(SHA-256, 5만 회)로 해시해서 저장하고, 원문은 저장하지 않습니다. 비밀번호 찾기 기능은 없습니다.
- 서버가 받은 값을 모두 다시 검사합니다. 접속자 1명당 초당 20건, 채팅은 1.5초에 1건까지만 받습니다.

## 이미 배포해 둔 경우 업데이트 방법 (GitHub 연동)

바뀐 파일 3개를 GitHub 저장소의 같은 위치에 덮어쓰면, Cloudflare가 자동으로 다시 배포합니다.

| 파일 | 위치 | 비고 |
|---|---|---|
| `index.html` | `public` 폴더 안 | 게임 화면 |
| `index.js` | `src` 폴더 안 | 서버(채팅·계정 추가) |
| `wrangler.jsonc` | 맨 바깥 | 계정 저장용 `VAULT` 추가. **`"name"` 값을 바꿔 쓰고 있었다면, 새 파일에서도 같은 이름으로 고쳐서 올리세요.** |

## 배포 방법 A — 터미널 (약 10분, 가장 확실)

1. **Cloudflare 가입:** https://dash.cloudflare.com/sign-up 에서 무료로 가입합니다. 카드 등록은 필요 없습니다.
2. **Node.js 설치:** https://nodejs.org 에서 LTS 버전을 받아 설치합니다.
   - Wrangler 공식 지원 OS: Windows 11, macOS 13.5 이상, 최신 Linux. Windows 10은 공식 지원 대상이 아닙니다.
   - Windows PowerShell에서 `npx`가 "스크립트를 실행할 수 없으므로" 오류를 내면, PowerShell 대신 **명령 프롬프트(cmd)** 를 쓰세요.
3. **압축 풀기:** 이 zip 파일을 풀고, 풀린 `monggeul-island` 폴더에서 터미널을 엽니다.
   - Windows: 폴더 빈 곳을 우클릭하고 "터미널에서 열기"를 누릅니다.
   - Mac: 폴더를 터미널 아이콘으로 끌어다 놓습니다.
4. **아래 3줄을 차례로 입력합니다.**
   ```
   npm install
   npx wrangler login
   npx wrangler deploy
   ```
   - `wrangler login`을 입력하면 브라우저가 열립니다. Cloudflare 로그인 후 "Allow"를 누릅니다.
   - 처음 배포할 때 `workers.dev` 하위 주소 이름을 정하라고 물으면 원하는 영문 이름을 입력합니다.
5. 배포가 끝나면 `https://monggeul-island.<내이름>.workers.dev` 같은 **주소가 출력됩니다. 이 주소가 공유할 링크입니다.**

수정한 뒤 다시 올릴 때는 `npx wrangler deploy` 한 줄만 입력하면 됩니다.

## 배포 방법 B — GitHub 연동 (터미널 없이)

1. GitHub에 새 저장소를 만들고, 이 폴더의 파일을 웹에서 끌어다 올립니다. `node_modules` 폴더는 빼고 올립니다.
2. Cloudflare 대시보드에서 **Workers & Pages → Create → Import a repository**를 고르고, 방금 만든 저장소를 선택해 배포합니다.
   - Worker 이름은 `wrangler.jsonc`의 `name`(`monggeul-island`)과 **똑같이** 적어야 합니다. 다르면 빌드가 실패합니다.
   - Build command는 비워 두고, Deploy command는 기본값 `npx wrangler deploy`를 그대로 둡니다.
3. 그다음부터는 GitHub에 파일을 올릴 때마다 자동으로 다시 배포됩니다.

## 비용 (Cloudflare Workers 무료 플랜 기준)

- 실시간 서버(Durable Objects)는 **하루 요청 100,000건까지 무료**입니다. 한도는 매일 00:00 UTC(한국 시각 오전 9시)에 초기화됩니다.
- 요청은 이렇게 셉니다.
  - 접속 1번 = 1건
  - 접속자가 보내는 메시지 20개 = 1건
  - 서버가 보내는 메시지는 세지 않습니다.
- 이 게임은 걸을 때 초당 약 6~7번, 섬에 혼자일 때 초당 1번, 가만히 있을 때 0번 상태를 보냅니다.
  - 계속 걷기만 하는 1명 = 1시간에 약 1,170건 (6.5 × 3,600 ÷ 20).
  - **(추정)** 계속 걷기만 하면 하루 약 85명·시간까지 무료입니다.
  - **(추정)** 걷기 40%, 낚시·쉬기 60%로 섞으면 하루 약 190명·시간까지 무료입니다. 예를 들어 20명이 2시간씩 놀면 약 40명·시간입니다.
- 실행 시간 한도(하루 13,000 GB-초)도 있습니다. 섬 1개가 하루 24시간 내내 깨어 있으면 약 10,800 GB-초(128MB 기준)로, 무료 범위 안입니다.
- 무료 한도를 넘으면 그날 오전 9시(한국 시각)까지 새 접속이 실패합니다. 돈이 자동으로 나가지는 않습니다.
- 사람이 많아지면 Workers Paid 플랜(월 5달러부터)으로 올릴 수 있습니다.
